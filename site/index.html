01 How it works

A small judge rates. Gearbox shifts. You keep typing.

No more switching variants and models by hand. Every prompt goes through the same three steps, and the judge never blocks a prompt.

01

The judge rates the prompt

A fast, cheap model rates each main-chat prompt low to max. Follow-ups like ok, go or continue skip the judge and reuse the last level.

02

Gearbox shifts effort

The level becomes the model's matching variant settings on every request of the turn, such as output_config.effort on Anthropic or reasoning.effort on OpenAI.

03

Subagents downshift

Each subagent gets its own level and, on its first prompt, the cheapest model on your provider's price ladder that fits. A fresh subagent has no cache to lose.

03 Features

Built to stay out of your way.

M

Your pick wins

Pick a variant yourself and Gearbox pauses for that session, and tells you once. An agent with its own model keeps it.

↓

Fails safe

A judge timeout, an unreadable answer or a provider error falls back to the last level, else medium. The judge never blocks a prompt.

◔

Context care

Cheaper compaction by the judge model, /gearbox handoff into a fresh session, a warning when the context gets swamped.

$

Stats, save mode, budget

Per-session turns, requests, tokens and cost. Save mode caps effort for a few hours. A daily budget turns save mode on at 80%.

✓

Benchmark your judge

/gearbox bench scores any judge model on 75 labelled prompts before you rely on it. In the end-to-end run, claude-haiku-5-5#none answered in about a second:

06 Commands

One command, no model turns.

Everything answers as a toast or a dialog. Nothing starts a model turn.

/gearbox
  • /gearboxStatus: level, model, mode, reason, context, save mode, today's spend
  • /gearbox auto on|offAutomatic effort on or off; on resumes a paused session
  • /gearbox set <key> <v>Change a setting, e.g. set bias -1
  • /gearbox save [on|off]Cap effort for a few hours
  • /gearbox statsTurns per level, requests, tokens, cost and judge cost
  • /gearbox bench [p/m]Score a judge model on 75 labelled prompts
  • /gearbox handoff [full]Continue in a fresh session seeded with a summary
  • /gearbox compact [note]Compact now, keeping your note in mind
  • /gearbox debugLast decision and the judge's raw answer
07 Install

Put it in drive.

  1. Open your global ~/.config/opencode/opencode.jsonc or a project opencode.jsonc.
  2. Add "opencode-gearbox" to plugins. Use the object form to set options.
  3. Restart OpenCode. The status bar loads with it. Run /gearbox bench to check your judge.
// opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "opencode-gearbox",
      "options": {
        "judge": { "model": "anthropic/claude-haiku-5-5#none" },
        "bias": 0
      }
    }
  ]
}
Requires OpenCode V2, 2.2.6 or later. Verified on Anthropic Messages, OpenAI Responses and OpenAI-compatible endpoints.
Which providers work?

Any model that exposes effort variants. Verified on OpenCode 2.2.6 with Anthropic Messages, OpenAI Responses and OpenAI-compatible endpoints (DeepSeek). Google and others should work the same way but are unverified. A model without variants runs unchanged and the bar says Paused: no effort control.

Will it override a variant I pick?

No. Pick a variant yourself and Gearbox pauses for that session and tells you once. /gearbox auto on resumes it.

Does it switch the main chat's model too?

Not on OpenCode 2.2.6, which doesn't fire the hook it needs, so the main chat gets effort only. Main-chat switching will be built for a later OpenCode that fires that hook, and only switch when the cost check says it beats a warm cache.

What if the judge is slow?

A turn waits at most judge.timeoutMs (4 s by default), then falls back to the last level, else medium. Pick a fast judge with a #none or low variant.
